# Análise de Dados - Netflix

## Sobre o Projeto

Projeto de análise de dados desenvolvido com PostgreSQL e Power BI, com o objetivo de responder perguntas de negócio sobre o catálogo da Netflix por meio de consultas SQL, modelagem de dados e dashboards interativos.

---

## Tecnologias Utilizadas

- PostgreSQL
- SQL
- Power BI
- Power Query
- DAX

---

## Etapas do Projeto

- Importação dos dados para o PostgreSQL.
- Criação de consultas SQL para responder às perguntas de negócio.
- Desenvolvimento de views para auxiliar a modelagem.
- Modelagem dos dados no Power BI.
- Construção do dashboard interativo.

## Principais Resultados

- O catálogo possui **8.807 títulos**.
- **69,62%** dos títulos são filmes.
- Os **Estados Unidos** concentram a maior quantidade de títulos.
- **Filmes Internacionais** e **Dramas** são os gêneros mais frequentes.
- **TV-MA** é a classificação predominante.
- **Julho** e **dezembro** registram o maior número de títulos adicionados.
